# PixelForge — Desktop App

The Electron desktop application. Runs real AI coding agents in live embedded terminals.

## Development

```bash
npm install
npm run dev
```

## Scripts

| Command           | Purpose                                   |
| ----------------- | ----------------------------------------- |
| `npm run dev`     | Launch the app in development mode        |
| `npm run build`   | Typecheck + production build              |
| `npm run smoke:pty` | Verify node-pty works inside Electron   |
| `npm run build:mac` | Package a macOS build (`.dmg`)          |

See the root [README](../../README.md) for the full project overview.
